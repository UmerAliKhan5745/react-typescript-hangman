# React TypeScript Hangman

A browser-based Hangman game built with React, TypeScript, and Vite. The project demonstrates component-driven UI design, keyboard interaction, game-state handling, and responsive styling.

## Features

- Interactive on-screen keyboard
- Dynamic word and drawing components
- Win and loss state handling
- Type-safe React components
- Fast local development with Vite

## Tech stack

- React 18
- TypeScript
- Vite
- CSS Modules

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```
